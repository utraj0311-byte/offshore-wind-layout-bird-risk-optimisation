# Metric 2a — designated-turbine Gaussian distance metric (formerly Model 5)

## Purpose and connection to other metrics

The positional metrics 1a–1d use prescribed fields; Metric 2a instead tests whether a turbine's metric value can depend on the positions of other turbines. It is a geometric validation metric, **not** an empirically calibrated collision probability. Metric 2b follows it by using every unique turbine pair rather than a designated turbine. Directional metrics 3a and 3b subsequently add bird-flight direction and rotor projection/interaction.

## Mathematical implementation

For **fixed array index 0**, the original `SurroundednessRiskModel` (`source/coupled_risk.py`, `mode='interior_risky'`) calculates

```
Q_2a = sum(j=1..11) exp(-||X[0]-X[j]||^2 / (2*sigma_a^2))
sigma_a = 4*D = 960 m; D = 240 m
f2 = Q_2a / 11
f1 = 2 - 2*AEP_GWh / 760.663033300808
```

**Turbine index 0 remains fixed as the designated index**; it is not selected geometrically. Turbine relabelling changes the meaning of the metric; that is deliberate. The original `collisions()` routine returns the metric value used for optimisation.

## Parameters and model

- 12 turbines, 6000 x 6000 m square site; bounds apply to turbine **centres**, not whole rotor discs.
- Minimum Euclidean centre spacing: 4D = 960 m (66 inequality constraints; pymoo variable coordinate bounds).
- Turbine: 240 m rotor, 150 m hub, 15 MW rated; cubic 3–10.6 m/s power curve; 25 m/s cut-out.
- Jensen top-hat hub-centre wake model, `kw=0.04`, RSS combined deficit clipped to 0.95; thrust coefficient from undisturbed speed 0.8 below rated and 0.25 from 10.6 to 25 m/s.
- Wind `FROM 225°`, 360 sectors of 1° in **final** result (original config/source defaults to 12 and the final runner overrides the scenario in memory), seven bins of 4, 6, 8, 10, 12, 14, 16 m/s, Weibull shape 2/scale 10 m/s; directional sector weights proportional to `exp(2*cos(delta_from_225deg))`, both sets of weights normalized.
- NSGA-II population **60**, generations **60**, seed **42**, duplicate elimination, original `GridSampling(model_name='constant')` (50% random feasible / 50% jittered grid); installed pymoo 0.6.1.5 default genetic operators.

## Limitations

- The geometric metric is not a species-specific collision-rate estimate; effect depends on an assumed length scale.
- The designated index is arbitrary by construction; relabelling can change `Q_2a`.
- Reported GA endpoints are search outcomes, not global-optimality proofs.
- The final archive proves saved outputs and the code/data checks, but complete bit-for-bit rerun is **not possible from this ZIP alone** until missing modules and the original execution environment are recovered.
